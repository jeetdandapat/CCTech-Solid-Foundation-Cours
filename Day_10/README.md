# Day 10 - Testing Basics

## What I Learned

* Learned testing  basics: expected output vs actual output.
* Learned AAA pattern: Arrange, Act, Assert.
* Learned Google Test (GTest) in C++.
* Used `TEST()`, `EXPECT_EQ()`, `EXPECT_TRUE()`, `ASSERT_TRUE()`, `EXPECT_THROW()`, and `TEST_F()`.
* Wrote and ran 9 test cases for Circle, Rectangle, Triangle, and shape sorting.
* Learned Jest basics for JavaScript and API testing.
* Learned `describe()`, `it()`, `expect()`, mocking, and coverage.
