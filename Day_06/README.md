# Day 06 - C++ Classes, OOP Patterns, and STL

## Topics Covered

* Learned class design and hierarchy in C++.
* Studied public, private, and protected access specifiers.
* Learned virtual functions, override, and runtime polymorphism.
* Explored pure virtual functions and abstract base classes.
* Understood the purpose of virtual destructors.
* Practiced STL containers, algorithms, and lambda expressions.
* Used std::vector, std::sort, std::find_if, and std::unique_ptr.

## Assignment

* Created an abstract Shape base class.
* Implemented Circle, Rectangle, and Triangle classes using inheritance.
* Overrode area(), perimeter(), and describe() methods.
* Stored objects in vector<unique_ptr<Shape>>.
* Sorted shapes by area using std::sort and a lambda.
* Used std::find_if to find the first shape with area greater than 100.
* Demonstrated polymorphism and smart pointer usage in C++.
