# Day 8 - SOLID Principles and Design Patterns

## Topics Covered

* SOLID principles as a code review guide
* SRP, OCP, LSP, ISP and DIP
* God class, long functions, switch-on-type and direct dependencies
* Factory pattern
* Observer pattern
* Strategy pattern
* Command pattern
* Facade pattern
* Native C++ and web code patterns

## What I Learned

* SRP means one class should have one job.
* OCP means new features can be added without changing old working code.
* LSP means a child class should work correctly in place of its parent class.
* ISP means a class should not have methods that it does not need.
* DIP means code should depend on interfaces, not direct classes.
* A God class is one class that does too many jobs.
* Factory creates objects.
* Observer sends updates to other objects.
* Strategy uses different ways to do the same work.
* Command keeps an action inside an object.
* Facade gives one simple way to use many classes.
