I learned how a web request travels from a browser to a server.

I learned that DNS converts a domain name into an IP address.

I learned how HTTPS secures communication using SSL/TLS encryption.

I learned the difference between HTTP/1.1 and HTTP/2 and how HTTP/2 improves performance by sending multiple requests through a single connection.
